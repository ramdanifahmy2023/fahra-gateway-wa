# Dashboard Popup/Form Mobile Audit

## Tujuan
Audit bug tampilan form popup/modal dashboard ketika dibuka dari HP.

## Scope
- Cari semua pemakaian `Dialog` / `DialogContent`.
- Identifikasi pola layout yang bikin modal tidak nyaman di mobile.
- Buat rencana fix global + page-specific.
- Tidak deploy dulu sebelum audit jelas.

## Acceptance
- Daftar file/page terdampak.
- Root cause CSS jelas.
- Plan update minimal.
- Risiko + verifikasi mobile.
