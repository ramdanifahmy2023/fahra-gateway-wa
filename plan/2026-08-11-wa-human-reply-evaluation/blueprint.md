# WA Human Reply Evaluation

## Tujuan
Evaluasi kualitas balasan agent WA HRD agar lebih manusiawi untuk pelamar kerja.

## Scope
- Baca history chat WA terbaru dari DB.
- Audit konteks prompt/profile/knowledge/contact_memory.
- Rekomendasi konteks tambahan.
- Tidak ubah live behavior dulu kecuali diminta.

## Acceptance
- Ada sampel chat terbaru.
- Ada gap kualitas balasan.
- Ada daftar konteks prioritas.
- Ada next patch jelas.
